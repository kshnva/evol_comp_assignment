# Evolutionary Computing - Gecko Locomotion Optimization

Optimization of gecko locomotion gaits using evolutionary algorithms (CMA-ES) in a MuJoCo physics simulation environment. Developed for Assignment 2 of the Evolutionary Computing course at VU Amsterdam.

## Students
This code is written by Shania Sinha, Bos Sprik, Kushnava Singha and Frederieke Loth.

## Usage
To run this code please run the file 'gecko_main.py'. A separate statistical analysis can be performed after through 'statistical_tests.py'. Additionally, plots may be rendered after obtaining data from 'gecko_main.py' through example_plot_usage.py' and/or 'plots.py'.


## Requirements
Proper installation of the ariel package is required:
The code will run with (at least) the following packages and versions:
numpy 1.26.4
python 3.12.8
scipy 1.16.2
matplotlib 3.10.6
torch 2.2.2
evotorch 0.6.1
mujoco 3.3.6
